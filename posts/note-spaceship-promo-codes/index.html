Spaceship 优惠码使用指南

自建笔记建站开发

Spaceship 是 Namecheap 旗下的域名注册与云服务平台。它的优惠码分两类：新注册码（买一个没人注册过的新域名）和转入码（把已有域名从别家搬到 Spaceship）；码只对指定的后缀和业务生效，续费能用上的很少。

重点
  • 优惠码必须原样复制，大小写和数字都不能改，否则无法生效。
  • .com 新注册先试 COMPROS，失效再换 COM67，哪个便宜用哪个。
  • 以上大部分优惠码不适用于续费，只对新注册和转入生效。

1. 五个优惠码对照表

优惠码适用范围参考优惠最佳使用场景
COMPROS.com 新注册第一年约 $2.90（第三方信息，需验证）购买新的 .com 主域名
COM67.com 新注册$3.60/年（官方促销页）购买新的 .com 域名
NET19.net 新注册$4.78/年（官方促销页）购买新的 .net 域名
SPSR86多种域名后缀部分后缀注册优惠注册非 .com / .net 的其他后缀域名
SPST25多种域名后缀部分后缀转入优惠转移已有域名到 Spaceship

2. 先分清三种业务

优惠码能不能用，先看这笔订单属于哪一种业务。

  • 新注册（Registration）：购买一个目前没有人注册过的新域名。
  • 转入/转移（Transfer）：域名已经是你的，但想从别的域名商（如 GoDaddy、阿里云、腾讯云、Namecheap）换到 Spaceship 来托管。
  • 续费（Renewal）：以上大部分优惠码不适用于续费，续费通常按 Spaceship 的常规价格计算；Spaceship 续费本身较便宜，如 .com 续费约 $9.98/年。

3. 多后缀码的具体范围

  • SPSR86｜新注册：适用 .org（$3.44）、.me（$1.97）、.top（$0.98）、.info（$2.73）等多种常见后缀。
  • SPST25｜转入：把在其他注册商（如 GoDaddy、阿里云、腾讯云、Namecheap）的域名转移到 Spaceship 时享受折扣，如 .net 转入 $5.94。

两个单后缀码的价格区间：COM67 约 $3.60 - $3.80，NET19 约 $4.78 - $4.98（原价约 $11 以上）。

4. 使用步骤

  1. 查找并添加域名：打开 Spaceship 官网并登录账号，在搜索框输入想购买或转入的域名，点击 Add to Cart（添加到购物车）。
  2. 前往购物车：点击页面右上角的购物车图标进入结算界面。
  3. 输入优惠码（Promo Code）：在订单明细侧边栏或底部找到 Promo code 或 Add promo code 输入框，粘贴对应的优惠码——注册 .com 先试 COMPROS，不行就换 COM67；转移域名则填 SPST25——然后点击 Apply（应用）。
  4. 确认价格并支付：检查折后最终金额（通常包含小额的 ICANN 官费，约 $0.18/年），价格变动确认无误后完成付款。

5. 注意事项

  1. 单个订单限额/限用一次：大多数促销优惠码针对每个账户或每个订单限制使用 1 次，或单次只能优惠 1 个域名。
  2. 优先测试专享码：注册 .com 时按 COMPROS 再到 COM67 的顺序尝试，哪个便宜用哪个。

COMPROS 属于第三方渠道/专享码，价格未经官方页面确认，且可能仅限部分地区或新用户；最终以购物车里的实际折后价为准。
