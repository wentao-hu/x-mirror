对新词没兴趣了：找需求与做基础设施才是王道

查看原文（X）↗𝕏帖子需求研究

最近有个很明显的感受：我对新词没啥兴趣了。

追新词就是蹦单，今天一单，明天没了。我还是更享受那种每天都有人付钱、一直出单的感觉。

所以这几天一直在想需求的事。

那些做 API 中转站的、做模型服务商的、卖建站模板的、卖 SEO 技能的，其实都是在给做站的人提供基础设施。

它们都是先抓住一群人，再去挖这群人要什么，做出来一推，肯定有人用。

我现在觉得，找需求才是王道。最好是刚需、能持续，还是每个月都要付费的那种。

我是真羡慕的那些做基础设施的，那是真香啊，哈哈哈。
