把上一个工具的输出当下一个工具的输入：谷歌搜索与趋势的输入输出清单

自建笔记需求研究

哥飞在上海线下活动里再次重点提的一句话是：一定要有「上一个工具的输出，当做下一个工具的输入」的思维方式。工具本身各有各的功能，单看都是孤立的；真正决定效率的是把它们串成一条链——只要链条能循环，新的关键词、新的网页、新的网站、新的需求、新的功能就会源源不断冒出来。

为什么串联能持续产出新东西

  • 各类工具的接口其实很统一：有的支持输入关键词，有的支持输入域名或网址。
  • 输出也分几类：有的吐出关键词列表，有的吐出网站列表、网址列表。
  • 把前一个工具的输出直接喂给下一个工具，串联起来就能不断扩展，而不是每次从零开始想词。

谷歌搜索：一次搜索，四个输出同时拿到

拿最熟悉的谷歌搜索来说，同一个输入（关键词）其实能同时读出四样东西：

  • 下拉搜索：输入关键词 → 输出关键词列表。
  • 广告列表：输入关键词 → 输出正在投广告的网页列表。
  • 搜索结果列表：输入关键词 → 输出拿到了排名的网页列表。
  • People also search for：输入关键词 → 输出关键词列表。

而且这四类结果并不需要搜四次，一次搜索就可以四个输出同时得到——这也是它适合当链条起点的原因：输入端最便宜，输出端最丰富。

谷歌趋势：三种用法对应三种输出

  • 看词热度趋势：输入关键词 → 输出该词在指定时间范围内的热度趋势曲线。
  • 看对比词相对热度：输入两个关键词 → 输出相对热度，用已知词的搜索量估算未知词的搜索量。
  • 看相关查询：输入关键词 → 输出最近增长的相关关键词列表；也可以输出长期霸榜的相关关键词列表。

趋势这一环补上了搜索本身给不了的信息：不是「有哪些词和页面」，而是这个需求在涨还是在退，以及哪些相关词正在冒头、哪些一直稳。

先手动跑熟，再交给程序

哥飞的建议顺序很明确：初期直接手动操作，等用熟悉了、对每个工具的输入输出了然于胸，再用程序替你跑。反过来先写程序，往往连链条该怎么串都没想清楚。
