让 AI 帮你投外链：Claude Code + Claude in Chrome 自动填目录站的 6 个要点𝕏帖子

查看原文（X）↗

卧槽，投外链这种体力活，终于能甩给 AI 了：

Claude Code + Claude in Chrome 插件，直接在你自己登录好的 Chrome 里，一个个填目录站的提交表单。

跑了几轮，总结几个关键点：

1. 一定用自己日常的 Chrome，别用空白的自动化浏览器，Google 登录会直接被拦

2. 先给它写一份 SOP，产品介绍、logo、分类、联系邮箱全放进一个文件，每个站照着填

3. 每投一个站记一行 CSV，状态分清楚：已提交、付费跳过、验证码卡住、等邮件验证

4. 看到感谢页或"审核中"才算成功，按钮弹个 Success 不算

5. 只有付费通道的站，直接跳过

6. 验证码别让它硬刷，留着自己手动点

邮箱验证链接老被提前点失效？用 Gmail 的 +别名，一个站一个，贼好用。
